---
name: Client password handling
description: Security decision for administrator access to client credentials.
---

Администратор не должен видеть или восстанавливать текущий пароль клиента: в базе хранится только bcrypt-хеш. Для помощи клиенту используется администраторский сброс пароля с выдачей нового значения один раз в интерфейсе.

**Why:** Старый пароль невозможно получить из хеша без нарушения базовых принципов хранения секретов; показ паролей из базы создал бы лишний риск утечки.

**How to apply:** В будущих изменениях сохранять только хеши, не добавлять passwordHash или текущие пароли в ответы API. Для забытого пароля использовать только защищённый admin-only reset flow.

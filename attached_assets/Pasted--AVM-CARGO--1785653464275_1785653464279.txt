Создай современный сайт для карго-компании AVM CARGO
Создай современный, быстрый и адаптивный сайт для карго-компании AVM CARGO. Основная задача сайта — отслеживание посылок клиентами с момента регистрации до получения.
Используй React + Next.js, Supabase (PostgreSQL + Auth) и современный минималистичный дизайн в фирменных цветах (черный, белый, красный).
Роли пользователей
Создать две роли:
Клиент
Администратор
Главная страница
Разместить:
Логотип AVM CARGO.
Поле быстрого поиска по трек-номеру.
Кнопку «Отследить посылку».
Краткое описание компании.
Контакты.
Кнопки WhatsApp и Telegram.
Личный кабинет клиента
После входа пользователь видит только свои посылки.
В верхней части экрана разместить:
Логотип компании.
Поле «Добавить трек-номер» с кнопкой "+".
Кнопку «Мой QR».
Поиск по трек-номеру.
Вкладки «Посылки» и «Архив».
Отображение посылок
Каждая посылка должна отображаться отдельной красивой карточкой, похожей на дизайн в примере.
В карточке отображать:
крупный трек-номер;
описание товара;
вес;
стоимость доставки;
текущий статус;
дату создания.
Справа отображать цветную метку текущего статуса:
🟢 Выполнено
🟠 В пути
🔵 Доставлено
История движения
В каждой карточке должна быть вертикальная временная шкала.
Использовать следующие этапы:
Создана
Принята на китайском складе
Выехала с китайского склада
Прибыла в Алматы
Выехала из Алматы
Поступила в город получателя
Готова к выдаче
Выдана
Возле каждого этапа отображать дату и время.
Цвета:
🟢 выполненный этап;
🟠 текущий этап;
⚪ будущий этап.
История должна обновляться автоматически после изменения статуса.
Карточка посылки
При нажатии открывать подробную информацию:
трек-номер;
описание;
вес;
стоимость доставки;
комментарии администратора;
QR-код;
история изменений.
Добавить кнопку «Скопировать трек-номер».
Архив
После получения статуса «Выдана» карточка автоматически переносится в раздел «Архив».
Архив доступен клиенту и администратору.
Возможности клиента
Клиент может:
добавить новый трек-номер;
редактировать описание товара;
удалить посылку только до статуса «Принята на китайском складе»;
искать посылки по трек-номеру;
просматривать архив.
Административная панель
Администратор может:
создавать посылки;
изменять статус;
менять трек-номер;
менять вес;
менять стоимость;
добавлять комментарии;
удалять посылки;
просматривать архив;
восстанавливать посылки из архива.
На главной панели администратора вывести:
общее количество посылок;
количество активных;
готовых к выдаче;
архивных;
последние изменения.
Сканирование
Добавить кнопку «Сканировать посылку».
После сканирования QR-кода или штрихкода автоматически открывать карточку нужной посылки для быстрого изменения статуса.
Импорт и экспорт Excel
Добавить:
кнопку «Импорт Excel»;
кнопку «Экспорт Excel».
Импорт должен автоматически обновлять данные по совпадению трек-номера.
Поддерживаемые поля:
статус;
вес;
стоимость;
комментарий.
Поиск
Реализовать быстрый поиск по:
трек-номеру;
имени клиента;
номеру телефона.
Добавить фильтры по:
статусу;
дате;
архиву.
Уведомления
После изменения статуса клиент автоматически получает уведомление в личном кабинете.
Дополнительные требования
Современный минималистичный дизайн.
Полностью адаптивная версия для телефона и компьютера.
Высокая скорость загрузки.
Автоматическое сохранение изменений.
Подтверждение перед удалением.
Безопасная авторизация через Supabase Auth.
Удобная административная панель с минимальным количеством действий.
Карточки посылок должны выглядеть современно и быть максимально похожими на предоставленный пример, но с улучшенным дизайном, плавными анимациями и удобной навигацией.
Все изменения статусов должны сохраняться в истории с указанием даты и времени.
При изменении статуса карточка автоматически поднимается вверх списка, чтобы клиент сразу видел последние обновления.
